# Signals and Systems Course – SBU

This repository contains my programming assignments and final project for the Signals and Systems course at SBU.  

All implementations were done from scratch to strengthen understanding of both the theory and practical aspects of signal processing.  

## Assignments
- Working with continuous and discrete signals  
- Magnitude and phase analysis  
- Fourier series and Fourier transform  
- Inverse Fourier transform  

## Final Project
The final project is divided into two main parts:  

### Audio Processing
- Noise removal  
- Changing playback speed  
- Applying filters  
- Mixing voices  

### Image Processing
- CNN Forward Pass: convolution, pooling, and filters (e.g., edge detection, blur) to produce feature maps  
- Frequency & Phase Processing: FFT-based methods with filters such as high-pass, etc.  


📂 **Project Files**  
- `voice-processing.ipynb` → Audio processing tasks  
- `image-processing.ipynb` → Image processing tasks
